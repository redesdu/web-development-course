- Status: implemented; instructor factual review pending
- Kind: formative practice

- Estimated time: 15 minutes

## Practice objective

Students retrieve and distinguish the basic web-app, HTTP, URL, response-status, message-structure, and CRUD ideas needed to follow the main HTTP lesson.

## Format rationale

This set uses nine easy MCQs because each item asks students to discriminate between a correct course concept and a plausible nearby misconception. It does not replace the pilot lesson’s construction task or written explanation.
